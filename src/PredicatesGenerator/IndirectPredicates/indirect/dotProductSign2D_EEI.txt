// p, r and q form two vectors (p-q) and (r-q), q is the common point.
// dotProductSign2D: (p-q) dot (r-q).
// Assume that dq > 0.

//   (p-q) dot (r-q)
// = (px - lqx / dq)(rx - lqx / dq) + (py - lqy / dq)(ry - lqy / dq)
// = (px * dq - lqx)(rx * dq - lqx) + (py * dq - lqy)(ry * dq - lqy)

pxdq = px * dq
pydq = py * dq
rxdq = rx * dq
rydq = ry * dq
lx = pxdq - lqx
ly = pydq - lqy
gx = rxdq - lqx
gy = rydq - lqy
dx = lx * gx
dy = ly * gy
d = dx + dy
