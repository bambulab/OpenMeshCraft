// p, r and q form two vectors (p-q) and (r-q), q is the common point.
// dotProductSign2D: (p-q) dot (r-q).
// Assume that dq > 0.

//   (p-q) dot (r-q)
// = (px - lqx / dq)(rx - lqx / dq) + ...y... + ...z...
// = (px * dq - lqx)(rx * dq - lqx) + ...y... + ...z...

pxdq = px * dq
pydq = py * dq
pzdq = pz * dq
rxdq = rx * dq
rydq = ry * dq
rzdq = rz * dq
lx = pxdq - lqx
ly = pydq - lqy
lz = pzdq - lqz
gx = rxdq - lqx
gy = rydq - lqy
gz = rzdq - lqz
dx = lx * gx
dy = ly * gy
dz = lz * gz
d1 = dx + dy
d = d1 + dz
